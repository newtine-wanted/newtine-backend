4. Status

검토 완료 · concrete security finding 없음. 정적 경로 검토에서 새로운 Origin 우회는 발견되지 않았고, 금지 Origin에서 다섯 use case가 호출되지 않는 것을 직접 확인했다. 추가 controller 테스트는 품질 보강 권고이지 보안 결함 수정이 아니다.

초기 critical review에서 signup/login의 새 403이 TypedException/OpenAPI에 누락된 사실을 먼저 수정했다. 후속으로 모든 cookie-auth route의 Origin 헤더를 generated 계약에 노출하고, DB TLS 강제 변경은 G3.2-D 승인에 따라 제거했으며, stale generated baseline은 Nestia 전체 재생성으로 동기화했다.

리뷰 finding과 조치
ID 관찰 조치·재검증 상태
SH-CR-001 signup/login은 Origin 거부로 runtime 403을 반환하지만 초기 변경본의 TypedException과 OpenAPI에는 403이 없었다. 두 route에 ApiException.Forbidden을 추가하고 contracts를 재생성했다. contract test가 signup/login의 403과 pipeline maxItems=100을 확인한다. fixed
SH-CR-002 runtime은 인증 route에서 Origin을 요구하지만 초기 generated OpenAPI의 해당 route parameters가 비어 있었다. 5개 cookie-auth POST에 optional typed origin header를 연결하고, 설명에 누락 시 route guard가 403을 반환함을 명시했다. SDK·e2e·OpenAPI를 함께 재생성하고 contract test로 고정했다. fixed
SH-CR-003 Cloud Run에 애플리케이션 TLS CA 자원이 없다는 배포 전제가 확인됐다. G3.2-D 승인에 따라 애플리케이션의 TLS mode/CA 강제와 전용 preflight를 제거하고, provider·네트워크 transport 책임을 운영 항목으로 남겼다. resolved · app-level TLS prerequisite removed
SH-CR-004 현재 source와 HEAD의 generated baseline이 이미 어긋나 metadata 추가·stale onboarding 제거가 보안 diff에 섞였다. generated SDK·e2e·OpenAPI를 수동 병합하지 않고 contracts:all로 동일 source에서 재생성했다. required artifact와 stale route 부재를 contract test로 확인하며, 커밋 시 baseline sync와 보안 변경을 별도 변경 단위로 분리할 수 있도록 기록한다. non-blocking risk · worktree fixed, commit split pending
SH-CR-005 승인 기준은 same-origin·허용 cross-origin·금지 cross-origin·Origin 부재 요청을 controller/integration 경로에서 확인하도록 요구하지만, 현재 HTTP 증거는 missing-origin signup/refresh/logout 일부에 그친다. login·withdraw와 금지 Origin의 세션 발급·회전·폐기 불변은 직접 검증되지 않았고 full smoke도 완료되지 않았다. 정적 호출 순서는 유스케이스·cookie effect 전에 Origin을 검사하는 것으로 확인했지만, 인수 전 다섯 인증 route에 대해 허용 Origin 성공, 누락·금지 Origin 403, Set-Cookie 부재, 세션 상태 불변을 HTTP 테스트로 남겨야 한다. non-blocking test coverage improvement · runtime bypass not found
SH-CR-006 runtime image는 devDependencies와 해당 script를 복사하지 않지만, README는 이 명령을 배포 pipeline 또는 운영 DB 접근이 가능한 일회성 작업에서 실행하도록 안내한다. 현재는 image 내부 실행을 요구하는 계약이 아니므로 보안 finding은 아니다. image-only 배포를 선택하면 build workspace/CI 실행 단계를 명시하거나 preflight 전용 image stage를 추가한다. 현재 소스 worktree에서의 config fail-closed 음성 검증과 실제 DB handshake 미실행은 별도 항목이다. finding 아님 · 실행 대상은 pipeline/one-off로 문서화
잔여 위험과 검증 공백. full test:smoke와 실제 DB handshake는 환경 제약으로 실행하지 못했지만, 이는 현재 코드에서 확인된 보안 finding이 아니다. G4-C에 따라 rate limit은 process-local이며 수평 확장 시 전역 quota가 아니다. controller 테스트 보강은 비차단 품질 개선 항목이다. 외부 권한으로 실행한 rate-limit smoke는 통과했다.
