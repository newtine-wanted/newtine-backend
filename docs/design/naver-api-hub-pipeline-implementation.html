승인 기준

설계 · 사용자 “구현 시작” 승인. 검색 공급자·설정 안내·집중 테스트만 변경.

현재 구현

naverNews.provider.ts 검색 URL을 API HUB로 전환하고 X-NCP-APIGW-API-KEY-ID/KEY 및 format=json을 적용했다. 기존 환경변수 이름과 빈 값은 유지했고 .env.example·README에 새 키 발급처와 오류 진단을 안내했다. naverProvider.test.ts에 요청·매핑·실패 계약 검증을 추가했다.

기술 상태

구현 완료. 승인 범위와 일치. 커밋·푸시·실서비스 호출 없음.

이슈 기록

해결됨: 새 워크트리에서 node_modules가 없어 저장소 루트의 설치된 의존성을 임시 심볼릭 링크로 연결하여 검증했다. 명령 모두 통과 후 링크를 제거했다. 다시 검증할 때 의존성 설치 또는 같은 연결이 필요하다. 열린 구현 이슈 없음.
