Docker ttsc 빌드 캐시 개선 구현 제어

구현 중 · 기준 설계: 설계 문서

기준 설계

승인 범위
Dockerfile의 ttsc BuildKit cache mount와 .dockerignore의 **/node_modules/ 보완. 메모리·컴파일러·runtime 구조는 유지한다.
불변식
runtime 동작과 dist 산출물 계약을 변경하지 않고, cache miss는 clean plugin build로 복구된다.

현재 구현

Dockerfile에는 plugin cache mount를 적용했고, .dockerignore에 중첩 node_modules 제외를 적용했다. 첫 검증에서 관찰된 3.26GB context를 줄이는 것이 이번 검증의 핵심이다.

구현 상태

구현 완료 — 승인 범위인 cache·context 개선은 확인했다. 기존 batch TypeScript 오류 때문에 최종 image 생성만 별도 미검증 상태다.

검증 계획

  1. git diff --check로 Dockerfile·ignore·문서 문법을 확인한다.
  2. context transfer가 중첩 dependency 없이 수 MB 수준인지 확인한다.
  3. 변경된 Dockerfile로 첫 build를 실행해 context 크기와 cold plugin compile 결과를 확인한다.
  4. 같은 builder에서 두 번째 build를 실행해 ttsc plugin 재컴파일 감소를 확인한다.
  5. 기존 애플리케이션 runtime stage가 정상적으로 유지되는지 확인한다.

검증 공백과 잔여 위험

  • CI의 ephemeral builder에서는 local cache mount 효과가 재현되지 않을 수 있다.
  • 아키텍처 전환 시 동일 cache id 재사용 여부를 확인해야 한다.
  • 설계 이해 점검 결과는 HTML local state이며, 대화에 자동 전달되지 않는다.
