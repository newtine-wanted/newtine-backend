구현 상태

기술 구현 완료 · 운영 제어 보류. 승인된 scope의 영속 모델·회원 전용 API·조회 연결·계약 생성을 구현했고 로컬 소스·빌드·단위·통합·계약 검증과 격리 PostgreSQL migration·HTTP smoke를 통과했다. 리뷰에서 확인한 누적 체류·동시 동일 ID·current-state 시점 문제와 수용 시각·fixture·rollback 검증 공백도 보완하고 실제 PostgreSQL action smoke를 통과했다. 구현 이해 점검과 운영 환경의 실제 preflight는 운영 제어 보류 사유로 남긴다.

승인 기준선

명시 행동은 LIKE(+2), SKIP(-3), PASS(0)이며 현재 상태의 기여분만 주제 선호에 반영한다. 상세 체류는 별도 열람 기록으로 누적하고 10초부터 +0.5, 30초부터 최대 +1을 부여한다. 동일 eventId/viewId 재전송은 멱등 처리하고, 이벤트·기여·선호 갱신은 한 트랜잭션으로 처리한다. GET /issues/:issueId는 부작용 없이 myAction을 제공하고 GET /me/liked-issues는 기존 계약을 유지한다.

검증 증거

통과: 아래 소스·빌드·계약 게이트는 현재 worktree에서 실행했다.

npm run format:check                         # pass

커밋 전 예상 실패: node scripts/check-generated.mjs는 아직 커밋되지 않은 의도적 generated 변경·신규 파일을 HEAD와 비교하므로 실패했다. 새 산출물은 contracts:check로 생성·검사했으며 커밋 후 안정성 검사가 통과할 상태다.

실제 DB·HTTP: Docker 격리 PostgreSQL에 npm run db:migrate를 적용하고 기존 피드·상세 smoke 및 신규 행동 HTTP smoke를 통과했다. 신규 smoke는 LIKE/SKIP/PASS 전환·멱등/충돌·myAction·관심 목록·상세 201/200·체류 경계·소유권·선호 원자 갱신을 확인했다. 추가 action smoke에서 여러 view 합산·교차 회원 동일 ID 동시성(200/409, 201/409)·소유권·만료·실패 trigger rollback을 확인했다. 저장 실패 rollback은 이제 커밋된 재현 경로로 검증되었고 운영 환경의 preflight만 별도 공백으로 남아 있다.

읽기 전용 최종 점검: 인증 경계·accepted_order 최신 판정·delta/체류 포화·멱등 충돌·migration fail-closed·generated 경로를 코드와 계약에 대조했고 점검 중 DI provider alias와 progress 최종 UPDATE의 DB 시각 만료 guard를 수정한 뒤 게이트를 재실행했다.

구현 시나리오: 전환표 12개, 같은 eventId 재시도·payload 충돌·회원 교차, 9999/10000/29999/30000ms 경계, 서버 경과시간 초과, 단조 누적·만료·철회, rollback 경계, 관심 목록·피드 회귀, generated OpenAPI/SDK 경로를 정책·서비스·계약 테스트와 코드 검토로 확인했다. 실제 DB의 경쟁·rollback 시나리오는 ACT-004와 커밋된 action smoke에서 해소했고 운영 preflight만 남아 있다.

검증 공백과 잔여 위험

  • 격리 PostgreSQL에서 새 contribution/view 테이블의 FK·CHECK·index와 migration 적용을 확인했고, 기존 이벤트가 있는 DB에서 fail-closed preflight를 실행하는 별도 fixture는 남아 있다.
  • 교차 회원 동일 eventId/viewId 경쟁·여러 view 합산·소유권·만료·실패 trigger rollback은 커밋된 action smoke로 확인했다. 같은 사용자·같은 이슈/같은 category·온보딩 병행 경쟁은 추가 운영 검증이 필요하다.
  • 공개 철회·만료 뒤 progress 재시도와 운영 환경의 실제 migration preflight는 HTTP 통합 환경에서 확인해야 한다.
  • 구현 이해 점검은 로컬 HTML에만 있고 아직 운영자의 답변 증거가 없어 상태를 운영 제어 보류로 유지한다.
