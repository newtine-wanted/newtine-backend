구현 기준선

영향 범위와 불변식
항목기준
변경 파일apps/api/src/main.ts만 변경한다.
포트 불변식PORT → API_PORT → 3000 순서를 유지한다.
호스트 불변식명시적 API_HOST는 유지하고 미설정 기본값만 0.0.0.0으로 한다.
금지 범위Cloud Run 배포 실행, DB·인증·라우트 변경, 환경변수 삭제는 하지 않는다.

이슈 기록

구현 이슈 레지스터
상태증상·원인조치·잔여 위험
완화됨Cloud Run이 PORT=3000을 보고했지만 애플리케이션은 127.0.0.1에만 바인딩할 수 있었다.PORT 우선·0.0.0.0 기본 바인딩을 적용했다. 실제 revision 재배포·로그 확인은 이 작업에서 실행하지 않는다.

기술 상태
승인된 단일 파일 변경이 컴파일·정적 게이트를 통과했다.
검증 공백
Cloud Run 재배포와 revision 로그 확인은 실행하지 않았다. Docker daemon 접근도 현재 세션에서 허용되지 않아 실제 image 실행은 검증하지 않았다.
잔여 위험
Cloud Run에 DB_*와 production JWT_SECRET이 누락되면 포트 바인딩 전에 프로세스가 종료할 수 있다.
