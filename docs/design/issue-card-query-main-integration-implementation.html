승인된 실행 계약

  • 범위: 최신 origin/main merge, 공통 예외·module·export·생성 계약·migration 등록 해소, feed schema의 회원 전용 전환, auth principal wiring, 관련 검증.
  • 불변식: pipeline/onboarding과 issue-card-query API·repository·테스트를 모두 보존한다. 공개 issue 상세 의미와 pipeline 상태 머신은 바꾸지 않으며, feed session owner는 검증된 JWT principal.userId 하나뿐이다.
  • migration: 기존 issue-card-query migration history를 보존하고, guest column·constraint를 제거하며 user_id NOT NULL을 보장하는 ordered TypeScript migration을 추가한다. 모든 down은 데이터 삭제 없이 명시적으로 중단한다.
  • generated: source 통합 후 npm run contracts:all로 재생성한다.
  • 금지: rebase/force-push, PR 기능 삭제, generated 파일 수동 합성, JWT·refresh foundation 변경, raw x-user-id 또는 x-feed-guest-key fallback.
  • focused 검증: merge conflict 없음, git diff --check, auth/feed route matrix, migration·contract generation/check, typecheck, 관련 unit/integration, Compose smoke, build 및 저장소 gate.

현재 구현

PR worktree .worktrees/issue-card-query의 기존 hardening 변경을 checkpoint bca46e6로 보존했다. 현재 origin/main=1215526 인증 baseline merge의 충돌을 해소하는 중이며, 현재 main worktree의 사용자 변경은 건드리지 않는다.

  1. 기존 production issue-card adapter·ORM entity·test fixture 경계를 checkpoint로 보존했다.
  2. origin/main의 auth module·JWT principal·role·Compose 기반을 merge하고 공통 conflict를 합집합으로 해소한다.
  3. feed controller/service/repository/schema를 회원 JWT owner로 전환하고 guest credential 경계를 제거한다.
  4. source 통합 후 SDK/e2e/OpenAPI를 재생성한다.
  5. auth/feed route matrix, migration, Compose smoke와 저장소 gate를 실행한 뒤 원격 상태를 확인한다.
