# 구현 컨벤션

컨벤션은 여러 기능에 반복해서 적용하는 작성 규칙이다. 특정 기능의 설계나 선택의 근거를 이 문서에
추가하지 않고, 공통 규칙이 바뀔 때만 갱신한다.
