# 뉴스 파이프라인 보고서 목차

작성일: 2026-09-20. 이 문서의 **입력 스크립트는 LLM 프롬프트**를 뜻한다. 단계별 파일에 실행 명령, 입력 데이터 구조, 저장된 실제 결과와 비용을 정리했다. 신규 API 호출 없이 기존 코드와 실행 스냅샷으로 작성했다.

## 먼저 확인할 실행 버전

| 단계 | 현재 코드 | 문서에 담은 실제 실행 |
| --- | --- | --- |
| 1단계 | 주제만 최대 3개, 그 외 최대 1개 | 지역만 1개, 그 외 3개였던 전체 실행. 새 비주제 제한은 미실행 |
| 2단계 | 최근 7일, 언론사 2곳 이상, 최대 5기사 | 전체 실행의 실제 결과 |
| 3단계 | 요약 본문 1~2문장 | 축약 반영 후 단독 재실행 40개 |
| 4단계 | 규칙 + 공격적·편향적 표현 검사, 수정 시 요약 1~2문장 | 축약 전 3단계 결과에 대한 실제 검증 39개 통과/1개 보류. 새 3단계 결과는 미검증 |
| 5단계 | 이슈 저장·공개 | 미구현·미실행, 본 문서 범위 제외 |

**이 문서는 최신 설정으로 연결 실행한 단일 1~4단계 성공 보고서가 아니다.** 전체 실행과 이후 3단계 단독 재실행을 나란히 기록한다. 39개 통과 판정을 새 요약 40개에 적용하면 안 된다.

입력 예시는 저장 스냅샷과 호출 코드를 바탕으로 재구성했다. 원시 HTTP 요청/응답 로그가 아니며, 본문 생략 및 표시용 축약은 각 예시에 명시한다. `{{...}}`는 런타임 치환 변수이고, `{{uxWriting}}` 전문은 3단계 파일의 부록에 있다.

## 전체 실행 흐름

````text
DB 카테고리·후속 추적 대상
  → 제목 검색 및 후보 추출 → 후보 중복·관련성 정리
  → 이슈별 기사 선별 → 기사 본문 수집·데이터 생성
  → 규칙 검사·표현 검사 → 통과 또는 보류 기록
````
