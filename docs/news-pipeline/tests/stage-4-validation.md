## 시나리오

1. 형식·DB 코드·점수·근거 ID 검증. 규칙 실패 시 최초 의미 검증 호출 생략.
2. 독립 취재 근거 그룹 없이 사실·모순·UX 검증 결과로 통과.
3. 실패한 필드만 1회 수정, 원본 보존, 다른 필드 수정 거부.
4. 수정 후 재실패 또는 형식 오류는 HELD, 재수정하지 않음.
5. 마지막 의미 검증 API 실패 후 재개 시 이전 검증·수정 호출 재사용.
6. DB에서 완료된 3단계만 입력 허용, 동일 입력 완료 결과 재사용.
7. 실행 중복 차단, 만료 소유자 저장·완료 거부, 기존 소유자의 fail 무효.
8. 기존 공개 이슈 개수 불변 및 실제 공개 없음.
