## 실제 PostgreSQL 연동

기존 전용 Docker PostgreSQL 18/pgvector, 영속 볼륨과 기본 스키마·공통 마이그레이션·1단계 마이그레이션 위에 `Migration20260920000100NewsCollection`을 적용했다. 확장 설치와 인덱스 생성 성공. API/LLM은 결정적인 대역을 사용했다.

- `pg_trgm` 한글 동일 제목 유사도 1, 내림차순 상위 10개 확인.
- 최근 7일 경계 포함, 그보다 오래된 게시·미공개·철회·미래 게시·게시 시각 누락 제외. 생성 시각이 아닌 게시 시각으로 조회.
- 미완료 1단계 실행 입력 거부.
- 후보 4개 처리: 중복 1개, 선정 1개(5기사), 기사 부족 2개(관련 기사 1개/검색 결과 0개).
- 중복 후보는 검색 생략. 원문 도메인 기반 등록 언론사 우선, 부모 이슈 연결 보존.
- 관련성 LLM 실패 후 동일 실행 ID·원래 시간 범위로 재개. 저장된 중복 판정과 검색 결과 재사용. 실패한 호출 사용량도 보존.
- 완료 재실행에 검색/모델 추가 호출 없음. 별도 CLI 프로세스에서도 동일 결과 내보내기 성공.

- 전체 실제 후보에 대한 2단계 일괄 실행 및 편집 품질 검토는 미실시. 실제 표본에서는 2건 이상 관련 기사가 남는 성공 사례를 확보하지 못했고, 선정 성공·우선순위·최대 5개는 단위/DB 테스트로 검증했다.
