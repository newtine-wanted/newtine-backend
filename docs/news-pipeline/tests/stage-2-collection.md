## 2단계 피드백 반영 검증

- 대표 기사 저장 필드와 선택 번호를 추가했다. 대표 번호는 근거 목록 안에 있어야 하며 병합 후에도 대표 기사를 보존한다.
- 기사 입력에 명시적인 index를 붙여 모델이 순서를 세는 과정의 오류를 줄였다. 제목 추출에는 본문·설명·언론사·날짜를 추가하지 않았다.
- 후보 추출 프롬프트에 구체적/포괄적 예시와 대표 기사를 먼저 선택하는 절차를 추가했다.
- 관련성 모델에는 단일 대표 기사 제목을 기준으로 전달하며, 같은 주제의 별개 행사·발표·결정은 제외한다.
- 2단계 7일 경계 포함, 7일 이전·미래 기사 제외 검증. 1단계 24시간 필터 유지.
- 단위 테스트: 32개 통과(1단계 16, 2단계 16). 배치 빌드·타입 검사·변경 코드 ESLint 통과.
- 기존 테스트 기사가 남아 비교 테스트가 충돌했던 문제는 실행마다 고유한 테스트 제목을 사용하는 방식으로 해결했다.
- 실제 모델 표본: 저장된 `주거` 검색 기사 제목에서 최대 5개를 재추출했다. 최초에는 잘못 센 기사 번호가 나타나 index를 명시했다. 이후 대표 제목 대응은 확인했으나 포괄 제목이 남아 대표 기사 우선·일반화 금지 예시를 강화했다.
- 최종 추출 예: `노원구 한성숙 태릉골프장 주택공급 교통대책`, `행안부 8월 호우 이재민 주거 안정 지원`, `이재명 대통령 청년의날 청년의견 청취`.
