## 남은 검증

- DB end-to-end 테스트 스크립트는 작성했으나 아직 실행·검증 완료하지 않음.
- 실제 네이버·OpenAI 호출과 후보 품질 검토 미완료.
- 운영 스케줄러·권한·네트워크는 별도 운영 검증 대상.
- Google Trends는 추후 개발로 이관하여 이번 완료 조건에서 제외.
