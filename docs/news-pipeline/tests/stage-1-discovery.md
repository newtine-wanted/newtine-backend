- 후보 적합성에 대한 사용자 검토 승인 완료 (2026-09-20). 제목만으로 불명확한 사건·잘린 제목 등은 본문을 확인하는 후속 단계에서 검증해야 함.
- Google Trends는 추후 개발. 기존 게시 이슈와 pg_trgm/LLM 중복 비교 및 본문 수집은 2단계 범위.

## 검토 반영: 최대 5개·중요 이슈·검색용 제목

- `npm run test:jest -- test/unit/newsDiscovery.test.ts`: 14개 통과.
- 6개 이상 설정과 모델 호출 제한 거절, 모델이 후보 6개 반환 시 저장하지 않고 실패 처리.
- 검색용 제목 공백 정규화, 60자 초과 거절, 근거 원래 기사 제목 보존 확인.
- 중요도 선택은 제목에서 확인되는 공공 영향·정책/법률 변화·새 전개 기준을 프롬프트에 명시하며, 불명확한 중요도를 추정하지 않고 5개를 억지로 채우지 않도록 지시. 의미상 중요도는 규칙으로 증명 가능한 조건이 아니므로 사용자 검토 대상.
- 배치 빌드·전체 타입 검사·변경 파일 ESLint 통과.
- 실제 OpenAI: 기존 `주거` 기사 제목만 입력, 검색용 제목 5개 반환(입력 2,011·출력 117 토큰).
- `행안부 호우 피해 이재민 주거 안정 지원`, `인천공항 소음피해 지원 확대`로 네이버 재검색: 각 50건 반환, 원래 근거 기사 각 1건 포함.
- 결과 기록: `.local/news-discovery/search-title-live-check.json`. 전체 기존 131개 후보를 새 규칙으로 재생성한 결과가 아니라, 주거 검색어의 새 추출·재검색 검증이다.


## 2단계 피드백에 따른 대표 기사·특정성 보완

- 대표 번호가 근거에 포함되는지 검증하고 후보에 대표 기사를 보존한다. 병합 시에도 대표 후보의 대표 기사를 유지한다.
- 번호가 명시된 제목만 LLM 입력으로 전달한다. 후보 생성 예시·대표 사건 중심 지시를 추가했다.
- 관련 단위 테스트 전체 32개 및 실제 DB discovery smoke 통과. 세부 표본 결과와 남은 특정성 한계는 `stage-2-collection.md`의 피드백 반영 검증 절 참고.
