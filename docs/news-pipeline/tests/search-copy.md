# 별도 제목 검색 테이블 검증 (2026-09-20)

- `news_issue_search`와 전용 GiST 제목 인덱스 DDL을 영속 로컬 PostgreSQL에 적용했다. 기존 `issues` 검색 인덱스는 제거된 상태다.
- 수집 스모크 통과: 최근 7일 경계·공개 상태·미래 시각 제외, 유사도 상위 10건, 제목 수정 반영, 비공개·삭제 원본의 검색 복사본 제거, 중복 판정·기사 부족·선정, 재개·동시 실행·소유권 보호.
- 타입 검사, 배치 빌드, lint, 뉴스 단위 테스트 81개 통과.
- 유료 API 호출 없음. 검색 테이블에는 동기화 시점의 최근 7일 공개 이슈만 저장한다. 실행 중 원본 변경은 다음 동기화에서 반영한다.
