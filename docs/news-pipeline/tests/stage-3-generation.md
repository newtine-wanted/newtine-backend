## 남은 문제 및 다음 단계

- 실제 표본에 모든 세대가 관련 있다고 선택하면서 각 세대의 직접 영향은 없다고 쓰는 불일치가 있다. 다른 표본에는 관점 주체가 ‘전문가’로 모호하게 표현됐다. 4단계 파생 데이터 간 모순·UX 라이팅·근거 일치 검증 대상으로 남긴다.
- 본문 수집 실패는 외부 언론사 응답에 따라 발생할 수 있다. 선정된 기사 외 추가 검색·대체 기사 수집은 하지 않는다.
- LLM 사실 정확성은 위 형식·코드·범위 테스트 통과만으로 보장하지 않는다. 이번 결과는 검증·공개 전 초안이다.
- 기존 로컬 DB에 활성 인물·기관·정당 데이터가 없어 실제 표본의 entity 분류는 비어 있다. 허용 목록 제한은 단위 테스트로 확인했다.
- 운영 스케줄러·권한·네트워크는 검증하지 않았다. 4단계 의미 검증과 5단계 저장·공개는 미구현이다.

## 관점 2개 고정 변경 검증

- 이전 nullable·1개 허용 정책은 사용자 최신 지시로 대체했다.
- JSON schema의 minItems/maxItems=2, 런타임에서도 정확히 2개 및 서로 다른 이해관계자·유효한 근거 ID를 검사한다.
- 기존 경계 테스트를 0/1/3개 거부와 2개 통과로 수정했다.
- 1~3단계 단위 테스트 43개, 배치 빌드, 로컬 DB smoke 통과.
