# 뉴스 수집 파이프라인 구현 현황

- 현재 상태: `IMPLEMENTED`
- 마지막 갱신: 2026-09-19
- 목표: 네이버 뉴스를 수집하고, 처리한 결과를 PostgreSQL에 저장한다.

## 현재 준비 상태

- 최신 `main` 코드 반영 완료
- Docker API와 PostgreSQL 실행 완료
- DB 마이그레이션 완료
- `GET /api/health` 응답 확인 완료
- 네이버 API와 OpenAI 환경변수 설정 완료
- 현재 로컬 기사·이슈 데이터: 0건

## 구현된 흐름

1. 검색어로 네이버 뉴스 검색
2. 기사 메타데이터 저장
3. 중복 기사 제거
4. 외부 기사 원문 확보
5. OpenAI로 후보 분류와 콘텐츠 생성
6. 검증된 이슈만 PostgreSQL에 저장·공개

## 남은 작업

- 첫 로컬 수집 실행 및 결과 검증
- 중요도 점수 계산·저장
- 이슈 날짜 계산·저장
- 실패 원인과 재시도 결과 기록
- 중복 실행 검증
- 검색어 확대
- 정기 자동 실행 추가

## MVP 완료 조건

- 기사 메타데이터가 저장된다.
- 원문 확보 결과가 기록된다.
- 이슈가 1건 이상 생성된다.
- 같은 입력을 다시 실행해도 중복 데이터가 생기지 않는다.
- 중요도와 날짜가 저장된다.
- 실패한 항목의 원인을 확인할 수 있다.
