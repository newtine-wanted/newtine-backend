# 문서 안내

문서는 목적에 따라 다음 영역으로 나눈다.

| 영역                                 | 질문                                         | 진입 문서      |
| ------------------------------------ | -------------------------------------------- | -------------- |
| [구현 설계](design/README.md)        | 코드를 어떤 구조와 흐름으로 구현하는가?      | `design/`      |
| [구현 컨벤션](conventions/README.md) | 기능이 달라도 반복해서 지킬 규칙은 무엇인가? | `conventions/` |
| [의사결정 기록](decisions/README.md) | 왜 이 선택을 했고 무엇이 미정인가?           | `decisions/`   |
| [정책과 계약](policies/README.md)    | 서비스와 외부에 어떤 규칙을 약속하는가?      | `policies/`    |
| [리뷰](reviews/security.review.html) | 구현을 검토한 결과와 잔여 위험은 무엇인가?   | `reviews/`     |

새 문서는 하나의 주제를 선택해 해당 영역에 작성한다. 구현 방법과 선택 근거를 한 문서에 섞지
않고, 서로 참조가 필요하면 상대 링크로 연결한다.
